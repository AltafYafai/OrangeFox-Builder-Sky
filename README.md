# OrangeFox Builder for Sky (Redmi 12 5G)

Automated builder for Unofficial OrangeFox Recovery.

## How to use
1. Go to the **Actions** tab.
2. Select the **OrangeFox Build [Sky]** workflow.
3. Click **Run workflow**.
4. Configure the parameters (default values are set for the `sky` device and `ofox-12.1` branch).
5. Wait for the build to complete and download the recovery from the **Releases** section.
